# Glossário

| Termo | Em português claro |
|---|---|
| **Engenharia reversa** | Desmontar um programa pronto para descobrir como ele foi feito |
| **REA** | Reverse Engineer Anything: ferramenta aberta que faz engenharia reversa de sites, apps e programas |
| **Proxy reverso** | Programa que fica na frente do site e repassa os pedidos. Aqui, o porteiro |
| **Página sombra** | A página com a mensagem sarcástica que quem é pego recebe |
| **Navegador automatizado** | Navegador pilotado por um programa, não por uma pessoa (Playwright, Puppeteer, Selenium) |
| **Modo de depuração / CDP** | Porta de controle do Chrome usada pelas ferramentas de desenvolvedor e pelo REA |
| **F12 / DevTools** | Ferramentas de desenvolvedor do navegador |
| **Mapa de código (source map)** | Arquivo que liga o código comprimido ao código original. Se ficar público, entrega o original |
| **Bundle** | O pacote de JavaScript que o site manda para o navegador |
| **Varredura** | Robô testando caminhos conhecidos atrás de falha (`/phpmyadmin`, `/cgi-bin/`, `/.env`) |
| **Ataque (direcionado)** | Scanner apontado para o seu site (sqlmap, nikto e afins). Vira aviso na hora, como "Ataque barrado" |
| **Webhook** | Endereço que recebe um aviso automático de outro sistema |
| **DNS reverso** | Perguntar "de quem é este IP?" para confirmar que um robô é mesmo do Google, por exemplo |
| **Upstream** | Onde o seu site real roda, para onde o porteiro repassa os pedidos |
| **Passe** | Cookie assinado que o visitante verificado recebe para navegar livre |
| **LGPD** | Lei Geral de Proteção de Dados, a lei brasileira de privacidade |
